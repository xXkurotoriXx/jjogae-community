# 쪼개 상황실 - 커뮤니티 에디션

치지직 스트리머 아홀로 루파 채널과 관련된 치즈 후원 내역, 통나무 보유량, 치지직 구독 티어와 최신 방송·영상 정보를 한 화면에서 확인하는 비공식 팬 제작 Chrome 확장 프로그램입니다.

사용자의 기록과 설정은 해당 Chrome 프로필 안에 저장되며, 필요한 정보는 사용자의 브라우저가 치지직·네이버·YouTube에 직접 요청합니다.

> 이 프로젝트는 CHZZK, NAVER, YouTube 또는 아홀로 루파의 공식 확장 프로그램이 아닙니다. 현재 버전은 기능 검증 중인 알파 버전이며, 사용 중 오류가 발생할 수 있습니다.

## 앞서서

본 배포자는 코딩에 대한 얕은 지식을 활용하여 본 확장 프로그램을 제작하며 발생하였던 에러의 부분수정과 API활용의 일부부분에서 AI(ChatGPT Codex)를 활용하여 VIVE CODING을 하였음을 미리 고지합니다.

## 주요 기능

- 치지직 페이지를 열지 않아도 ↻ **강제 전체 새로고침** 버튼 하나로 캐시를 무시하고 아홀로 루파 채널의 과거 후원 내역과 현재 정보를 모두 다시 확인
- 5분마다 올해 최신 후원 내역 첫 페이지, 통나무·구독·방송·영상과 네이버 카페 공지글을 자동 확인하고 마지막 자동 업데이트 시각 표시
- 직접 입력한 치즈 기록과 동기화된 후원 내역의 개별 삭제
- 전체·최근 30일·최근 7일·오늘 치즈 사용량 요약
- 최근 14일 막대그래프와 후원 종류별 원형 그래프, 점멸이나 위치 이동 없이 고정되는 초록색 마우스 강조
- 로그인한 치지직 계정의 아홀로 루파 채널 통나무 보유량 확인
- 아홀로 루파 치지직 구독 티어, 다음 갱신일과 누적 구독 개월 확인
- 라이브 방송 우선의 치지직 방송·VOD, 최신 클립과 YouTube 최신 영상 표시
- 네이버 카페 `공지&이벤트 소식` 게시판 전용 API로 공지글만 확인하고, 기록 화면의 치즈 기록보다 위에서 최근 20개 공지를 표시
- 카페 공지를 체크해 **선택 읽음** 처리하거나 **모두 읽음** 처리하면 목록에서 숨기고, 읽음 상태를 다음 자동 동기화 뒤에도 유지
- 네이버 카페 영역은 바로가기와 같은 카페 로고로, 통나무·치지직 구독·치즈 후원 기록은 같은 형태의 치지직 로고로 구분
- 치지직 로그인 닉네임 표시 및 `YYYYMMDD` 숫자 입력도 지원하는 YouTube·치지직 구독 시작일 설정
- JSON·CSV 내보내기와 검증된 JSON 가져오기
- 치지직, 루파의 쪼개 양식장 카페, YouTube, X, 팬심 바로가기

## Chrome에 설치하는 방법

이 확장 프로그램은 Chrome 웹 스토어에서 설치하는 방식이 아닙니다. 배포 ZIP의 압축을 푼 다음, Chrome 확장 프로그램 관리 화면에서 `manifest.json`이 들어 있는 폴더를 직접 불러오면 됩니다.

1. 이 저장소를 내려받거나 배포 ZIP의 압축을 풉니다.
2. Chrome 주소창에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 치지직 후원 내역을 확인하려면 같은 Chrome 프로필에서 네이버·치지직에 로그인합니다.
6. 확장 프로그램을 열고 ↻ **강제 전체 새로고침**을 누릅니다.

도구 모음의 확장 아이콘을 누르면 사이드 패널이 열리며, 대시보드의 **큰 화면** 버튼으로 일반 탭에서도 사용할 수 있습니다.

## 작동 방식

```text
사용자 조작
  └─ 쪼개 상황실 확장 프로그램
       ├─ 치지직·네이버: 로그인 확인, 아홀로 루파 후원 내역, 통나무 보유량, 구독 상태
       ├─ 치지직 공개 정보: 라이브, VOD, 클립, 채널 정보
       ├─ YouTube 공개 정보: 최신 영상과 공개 구독자 수
       └─ Chrome 로컬 저장소: 기록, 설정, 짧은 조회 캐시
```

## 동기화 기준

- 아홀로 루파 채널 ID와 일치하는 완료된 후원 내역만 저장합니다.
- 일반 후원 내역은 2023년부터, 완료된 파티 후원은 2024년부터 조회합니다.
- 진행 중인 미션과 대기 중인 파티는 누적 금액에서 제외합니다.
- 과거 치즈 기록 전체 조회와 교체 및 모든 현재 정보의 캐시 우회는 사용자가 ↻ **강제 전체 새로고침**을 눌렀을 때만 실행합니다.
- 5분 자동 동기화에서는 현재 연도의 최신 후원 내역 첫 페이지만 기존 기록에 합칩니다.
- 통나무 데이터는 아홀로 루파 채널 하나만 등록된 화이트리스트를 통과한 결과만 저장합니다.
- 치지직 구독정보는 아홀로 루파 채널 ID로만 조회하며 다른 채널 응답은 저장하지 않습니다.
- 아홀로 루파가 치지직 보유량 목록에 없으면 0으로 단정하지 않고 `100 미만/미표시`로 안내합니다.
- 공개 미디어와 통나무·구독·카페 조회 결과는 5분 자동 동기화 주기에 맞춰 로컬에 캐시합니다.
- YouTube·치지직 구독 시작일은 설정에서 `YYYYMMDD`, `YYYY-MM-DD`, `YYYY.MM.DD` 형식으로 입력할 수 있으며 실제 날짜만 저장합니다.

## 권한을 사용하는 이유

| 권한 또는 주소 | 사용 목적 |
| --- | --- |
| `sidePanel` | 확장 프로그램 대시보드를 Chrome 사이드 패널에 표시 |
| `storage` | 사용자의 설정과 조회 캐시를 현재 Chrome 프로필에 저장 |
| `alarms` | 브라우저가 실행 중일 때 5분 자동 동기화를 예약 |
| `api.chzzk.naver.com` | 아홀로 루파 후원 내역, 통나무 보유량, 구독 상태, 방송·VOD·클립·채널 정보 확인 |
| `comm-api.game.naver.com` | 현재 치지직 로그인 상태와 닉네임 확인 |
| `apis.naver.com` | 루파의 쪼개 양식장 `공지&이벤트 소식` 게시판 확인 |
| `www.youtube.com` | 아홀로 루파 YouTube 채널의 공개 최신 영상과 구독자 수 확인 |

## 개인정보와 데이터 보관

- 후원 내역과 직접 입력한 치즈 기록은 확장 프로그램 전용 IndexedDB에 저장합니다.
- 로그인 닉네임, 구독 시작일, 통나무 보유량, 치지직 구독 상태, 카페 최근 공지 목록·읽음 상태와 미디어 캐시는 `chrome.storage.local`에 저장합니다.
- 치지직·네이버·YouTube로의 요청은 사용자의 Chrome에서 각 서비스로 직접 전송됩니다.
- 설정 화면의 **모든 로컬 데이터 삭제**로 저장된 기록과 설정을 지울 수 있습니다.
- JSON·CSV로 내보낸 파일은 Chrome 다운로드 폴더에 생성되며, 이후의 보관과 공유는 사용자 책임입니다.

자세한 내용은 [개인정보처리방침](./PRIVACY.md)을 확인해 주세요.

## 데이터 내보내기

JSON 내보내기는 `jjogae-community-v1` 형식으로 설정과 치즈 기록을 포함합니다. 가져오기 과정에서 치즈 수량, 날짜, 후원 종류와 문자열 길이를 다시 검사하며 허용되지 않은 이벤트 형식은 저장하지 않습니다.

내보낸 JSON과 CSV에는 후원 메시지나 개인 활동 기록이 포함될 수 있습니다. 공개 게시판, 메신저 또는 다른 사람에게 전달하기 전에 내용을 확인해 주세요.

## 알려진 제한사항

- 치지직 동기화에는 서비스의 웹 내부 요청 주소가 사용되므로 치지직이 화면이나 응답 형식을 변경하면 기능이 중단될 수 있습니다.
- 사용자의 치지직 계정에 표시되는 범위보다 오래된 기록은 복원할 수 없습니다.
- 기록은 현재 Chrome 프로필에 저장되므로 Chrome 프로필이나 확장 프로그램을 삭제하기 전에 필요한 기록을 직접 내보내야 합니다.
- YouTube 공개 구독자 수는 YouTube가 공개 화면에서 제공하는 정밀도까지만 표시할 수 있습니다.
